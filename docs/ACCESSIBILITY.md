# 楼记 · 可访问性（TalkBack）走查记录

日期：2026-11-05
版本：v1.18.0
设备：Android Emulator `RiderClimbApi35`（API 35），启用系统 TalkBack（`com.google.android.marvin.talkback`）
字体缩放：1.0× 与 2.0×（`settings put system font_scale`）

> 说明：本会话所用模型无法直接查看截图，改用 `uiautomator dump` 的无障碍树（即 TalkBack 朗读的 content-desc/text）做真实结构核对。

## 1. 结论

核心三流程（列表 / 详情 / 表单）的读屏内容描述与状态朗读均正确；2.0× 字体下内容可滚动、无横向裁剪。发现并修复 1 处：列表卡片底部时间戳在 2.0× 下可能横向溢出，改为 `weight(1f)` + 单行省略，保证「详细信息」按钮始终可见。

## 2. 列表（读屏焦点顺序）

- 统计条：本月记录 / 免爬 / 会下楼（数字+文字）。
- 搜索框：`content-desc = "搜索位置、订单号、尾号、房号"`（TalkBack 明确朗读，不再只有占位符）。
- 筛选 chips：全部 / 要爬楼 / 免爬 / 会下来（Material FilterChip 带选中态）。
- 日期、活跃/已归档/回收站、排序。
- 记录卡片：状态印章文字（待确认/要爬/免爬）、位置、楼层房号、时间、`详细信息` 按钮。
- FAB `记一单`、`多选`、`设置` 均有可读标签。

## 3. 详情

- 顶栏标题=位置，`返回`/`编辑`/`更多` 均有 content-desc。
- 状态印章以文字朗读（待确认/不用爬楼等），台账字段名+值逐行可读。

## 4. 表单

- 爬楼决策三态（不用爬楼/要爬楼/待确认）以文字朗读。
- `从剪贴板填入`、`识别订单截图`、`使用当前位置`、`关闭` 均有标签。
- 位置必填字段、订单号、手机尾号等输入框可读。

## 5. 2.0× 字体

- 列表/详情/表单在 2.0× 下内容可滚动、无横向溢出；`详细信息` 按钮与时间戳经滚动后可见（正常滚动，非裁剪）。
- 修复：列表卡片时间戳改 `Modifier.weight(1f)` + `maxLines=1` + `overflow=Ellipsis`，避免与「详细信息」按钮抢宽度。

## 6. 残余

- TalkBack 真实焦点顺序逐元素遍历依赖人耳/无障碍事件，本走查以无障碍树核对等价覆盖；真机 TalkBack 手势遍历仍建议作为后续真机验证项。
